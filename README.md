Sizzle & Serve — a complete 2D cooking game set in a tiny diner. Orders roll in on the board; chop lettuce and tomato, grill patties, boil noodles, build each dish on the plate and ring the bell to serve before the ticket expires. Three days, three hearts, combo scoring, procedural WebAudio sounds and music, and a saved best service. Pure Canvas 2D, no libraries, runs entirely from static files in your browser.

## Run it

```sh
python3 -m http.server --directory game 8000
# then open http://localhost:8000 in a desktop browser
```
